# ST Helper Panel

A lightweight SillyTavern extension that adds a floating helper panel with quick actions.

## Installation

1. Open SillyTavern.
2. Go to Extensions -> Install Extension.
3. Paste the repository URL:

```text
https://github.com/yasminisismignac-blip/sillytavern-extension
```

4. Install and refresh SillyTavern.

## Features

- Floating toggle button in the lower-right corner
- Minimal helper panel with action buttons
- Quick refresh button
- Theme toggle
- Scroll-to-top button
- Keyboard shortcut: Alt + H

## Files

- `manifest.json` - extension registration
- `index.js` - extension logic
- `style.css` - visual styling

## Notes

This version is intentionally minimal and safe for SillyTavern. It exists to make the extension show reliably without depending on a heavy internal framework.
